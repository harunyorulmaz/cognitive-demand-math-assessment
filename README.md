# cognitive-demand-math-assessment
Supplementary materials and reproducible analysis code for a study on cognitive demand in international mathematics assessments.
# Cognitive Demand in International Mathematics Assessments

## Overview
This repository contains the supplementary materials and reproducible analysis code for a study examining the cognitive demand characteristics of international mathematics assessment items. The study conducts an item-level comparison of assessments from the International Baccalaureate Diploma Programme (IB DP) Mathematics, Advanced Placement (AP) Calculus, and A-Level Mathematics using a structured Cognitive Demand Index (CDI) in combination with psychometric modeling.

The repository is intended to support transparency, reproducibility, and methodological clarity in educational measurement research.

---

## Repository Contents

The repository is organized as follows:

- **analysis/**
  - Jupyter Notebook (`.ipynb`) containing all statistical analyses, including:
    - Data preprocessing
    - Cognitive Demand Index (CDI) scoring aggregation
    - Item Response Theory (IRT) modeling
    - Non-parametric statistical comparisons
    - Effect size estimation

- **appendix/**
  - **Appendix A**: *Example Cognitive Demand Index (CDI) Coding*
    - Illustrative examples of CDI coding across assessment systems
    - Dimension-level scoring (e.g., cognitive process level, representational complexity)
    - Justifications for coding decisions

- **README.md**
  - Documentation describing the purpose and structure of the repository

---

## Methodological Framework

The study integrates:
- A multi-dimensional Cognitive Demand Index (CDI) framework
- Item Response Theory (IRT) modeling
- Non-parametric statistical techniques for cross-system comparison

This combined approach enables examination of construct validity by linking intended cognitive demand with empirically observable item characteristics.

---

## Reproducibility

All analyses reported in the manuscript can be reproduced using the materials provided in this repository. The Jupyter Notebook contains the complete analytical workflow, including model specifications and statistical outputs corresponding to the reported results.

---

## Data Availability

Due to copyright and examination security constraints, original assessment items and raw response data are not publicly shared. The analyses are conducted on coded item-level data derived from authorized sources and used solely for research purposes.
